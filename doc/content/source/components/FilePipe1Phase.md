# FilePipe1Phase

!syntax description /Components/FilePipe1Phase

## Overview

`FilePipe1Phase` is a [FlowChannel1Phase.md] (a Thermal Hydraulics Module (THM) component) that
builds its 1D pipe mesh from a list of $(x, y, z)$ node coordinates read from the
[!param](/Components/FilePipe1Phase/csv_file) parameter, rather than from the
[!param](/Components/FlowChannel1Phase/length), [!param](/Components/FlowChannel1Phase/position),
[!param](/Components/FlowChannel1Phase/orientation), and
[!param](/Components/FlowChannel1Phase/n_elems) parameters used by a standard
[FlowChannel1Phase.md]. This allows the resulting pipe to follow an arbitrarily curved path rather
than only straight segments, which is needed for a coolant channel whose geometry is digitized
directly from a blanket CAD model, as used for the outboard blanket of the Fusion Nuclear Science
Facility (FNSF) in [!citep](Kong2022): each channel's CSV file of points is generated by a
Python script that samples points from the channel's original CAD/Cubit mesh, and
`FilePipe1Phase` then builds a 1D THM pipe mesh from that list of points.

The CSV file is read using `MooseUtils::DelimitedFileReader` and must contain exactly three
columns, giving the $x$, $y$, and $z$ coordinates of each node along the channel in order; the
number of points in the file determines the number of elements in the resulting 1D mesh, and the
cumulative distance between consecutive points determines the channel's total length.
